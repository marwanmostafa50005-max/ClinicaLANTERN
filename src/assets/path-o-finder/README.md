# path-O-finder brand assets

These two files are the mark of path-O-finder, the clinical reviewer's own pathology safety net for Australian general practice (copyright 2026 Marwan Morsy, all rights reserved). He ordered on 20 November 2026 that the part of the LANTERN that reads an uploaded pathology test carries this brand: "I wanna integrate the branding of path-O-finder into this part of the LANTERN". Copied unchanged from his path-O-finder repository (brand\). They are used only in the pathology upload block of the page.

Palette of path-O-finder, used only inside that block: teal #0E7C7B and #41BDB4, ink #243A3B, burgundy #7E1E2E and #B84452 (the single accent), deep panel #0E2A2B, paper #F7FAFA.
Its line: "Every result finds its path, and every path is one a clinician chose."

## pathofinder_lantern.svg (added 20 November 2026, 22:05)

The mark as the LANTERN shows it: the same name and the same glass, from the same outlines as pathofinder_ui.svg, without the line that file carries as an outline under the name ("Every result finds its path, and every path is one a clinician chose") and without the dark box behind it. The founder ordered one change to that line for the LANTERN: "pharmacist" in place of "clinician". So the page writes the line as text ("Every result finds its path, and every path is one a pharmacist chose.") and shows this mark above it. The picture is cut to the name, so it stands larger at the same height. Made by program from pathofinder_ui.svg, which is unchanged.
